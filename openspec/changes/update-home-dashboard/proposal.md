## Why

Главная страница сейчас показывает статичный заголовок «Learn Frontend» и общее описание сервиса
независимо от того, авторизован пользователь или нет, а карточки уровней сложности (Лёгкий/
Средний/Сложный) дублируют информацию, уже доступную в каталоге, и не несут действия. Обновлённый
дизайн должен персонализировать приветствие, сфокусировать подзаголовок на призыве к действию и
визуально усилить карточки статистики (Навыков/Тем/Вопросов) иконками и мини-диаграммами, приближая
их к референсному стилю.

## What Changes

- Заголовок дашборда заменяется на персонализированное приветствие: «С возвращением, {имя}» для
  авторизованного пользователя и «Добро пожаловать» для неавторизованного (без имени).
- Подзаголовок «Сервис для подготовки по фронтенду: ...» заменяется на «К чему приступим сегодня?».
- Карточки уровней сложности (Лёгкий/Средний/Сложный) удаляются из главной страницы. **BREAKING**
  для существующей раскладки дашборда и связанных тестов/E2E, которые ссылаются на эти карточки.
- Карточки статистики (Навыков/Тем/Вопросов) получают редизайн: иконка-бейдж слева и лёгкая
  декоративная мини-диаграмма справа в каждой карточке, в стиле предоставленного референса.
- В `app/globals.css` добавляются именованные цветовые токены на основе значений 9688E9, E1DDF6,
  3B3B3B (brand primary/soft/ink) и `@theme inline` alias'ы для использования в Tailwind-классах.

## Capabilities

### New Capabilities

- `home-dashboard`: приветствие на главной странице (персонализированное/анонимное) и визуальное
  представление карточек статистики каталога (без карточек по сложности).

### Modified Capabilities

(нет — существующие capability-спеки не описывают главную страницу)

## Impact

- Код: `app/(main)/(home)/_components/dashboard/dashboard.tsx`,
  `app/(main)/(home)/_components/dashboard/stat-card.tsx`,
  `app/(main)/(home)/_components/dashboard/dashboard.test.tsx`,
  `app/(main)/(home)/page.tsx`, `src/lib/auth/get-session.ts` (потребление `getCurrentUser`),
  `app/globals.css`.
- Тесты: обновление `dashboard.test.tsx` (снятие ожиданий по карточкам сложности, добавление
  проверки приветствия), возможное обновление `src/tests/e2e/catalog.spec.ts` /
  `src/tests/e2e/header-nav.spec.ts`, если они опираются на текст заголовка главной страницы.
- Зависимости: без новых npm-пакетов; иконки берутся из уже используемой иконочной библиотеки
  (`@repo/core`/lucide, см. design.md), диаграммы — лёгкая декоративная SVG-разметка без графической
  библиотеки.
- Данные: используется уже существующий `getCurrentUser()` (server-only) и `useGetAuthMe` (client)
  для определения имени пользователя; новых API-эндпоинтов не требуется.
