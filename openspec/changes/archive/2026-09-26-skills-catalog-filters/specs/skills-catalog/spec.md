## Purpose

Показывает пользователю список доступных навыков в виде карточек на главной странице и явно
сообщает о состоянии загрузки, ошибке запроса или отсутствии результатов.

## ADDED Requirements

### Requirement: Отображение списка навыков

Система SHALL отображать по одной карточке на каждый навык, возвращённый `GET /api/skills`. Карточка
SHALL показывать тему, сложность (на русском языке), название и количество вопросов, и SHALL вести по
клику на `/catalog/{id}` соответствующего навыка.

#### Scenario: Успешная загрузка списка

- **WHEN** запрос `GET /api/skills` завершается успешно и возвращает непустой список
- **THEN** для каждого элемента списка отображается карточка с темой, названием, сложностью и
  количеством вопросов
- **THEN** карточка ведёт по ссылке `/catalog/{id}` этого навыка

### Requirement: Индикация загрузки

Пока запрос списка навыков выполняется, система SHALL показывать сетку из плейсхолдеров-скелетонов
вместо карточек и SHALL не показывать текст ошибки или текст об отсутствии результатов в этот момент.

#### Scenario: Запрос ещё выполняется

- **WHEN** запрос `GET /api/skills` находится в состоянии загрузки
- **THEN** отображается сетка скелетон-карточек
- **THEN** текст ошибки и текст об отсутствии результатов не отображаются

### Requirement: Состояние ошибки

Если запрос списка навыков завершается ошибкой, система SHALL показать сообщение об ошибке вместо
сетки карточек.

#### Scenario: Запрос завершился ошибкой

- **WHEN** запрос `GET /api/skills` завершается ошибкой
- **THEN** отображается сообщение "Не удалось загрузить список навыков. Попробуйте обновить страницу."
- **THEN** карточки навыков не отображаются

### Requirement: Пустой результат

Если запрос успешно завершился, но список навыков пуст, система SHALL показать сообщение об
отсутствии результатов вместо пустой сетки.

#### Scenario: Список навыков пуст

- **WHEN** запрос `GET /api/skills` завершается успешно и возвращает пустой список
- **THEN** отображается сообщение "Скиллов по запросу не нашлось."
- **THEN** сетка карточек не отображается
