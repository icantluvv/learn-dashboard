## Why

Карточка навыка в каталоге уже ведёт на `/catalog/{id}`, но страница по этому адресу — заглушка,
которая просто печатает `id`. Пользователь не может увидеть ни название навыка, ни список вопросов
по нему, то есть основной сценарий изучения навыка не работает.

## What Changes

- Контракт `GET /api/skills/{id}` добавлен в OpenAPI-спецификацию: возвращает `title` и
  пронумерованный (по порядку массива) список `questions` навыка по его `id`, отвечает `404`, если
  навык с таким `id` не найден.
- Мок-обработчик `GET /api/skills/{id}` реализован в `packages/api/base/mock-scenarios.ts` поверх
  расширенного набора мок-данных (`title`/`questions` на каждый `skill-id`), включая ветку "не найдено".
- Страница `app/catalog/[id]/page.tsx` полностью реализована: выполняет SSR-префетч
  `GET /api/skills/{id}` через React Query (`HydrationBoundary`/`dehydrate`, как на главной), и сама
  отрисовывается на сервере — без `'use client'`-компонентов, так как страница не содержит
  интерактивности.
- Страница использует ту же обёртку `page-wrapper v-stack gap-12 md:flex-row`, что и главная
  страница, чтобы визуальный ритм (отступы, брейкпоинт для строки на десктопе) был единым по
  проекту.
- На странице отображаются заголовок навыка (`title`) и нумерованный список вопросов (`questions`).
- Если навык с таким `id` не найден, показывается состояние "не найдено" (`notFound()` Next.js →
  страница 404) вместо пустого контента.
- Если запрос завершается ошибкой, показывается сообщение об ошибке в том же визуальном стиле, что
  и `CatalogError` на главной странице.

## Capabilities

### New Capabilities

- `skill-detail`: страница навыка `/catalog/{id}` — отображение заголовка и пронумерованного списка
  вопросов, состояние "навык не найден", состояние ошибки загрузки.

### Modified Capabilities

_(нет — `skills-catalog`/`skills-catalog-filters` ещё не заархивированы в `openspec/specs/`, их
поведение этим изменением не затрагивается)_

## Impact

- **API-контракт**: новый файл `api/src/paths/api_skills_id.yaml` (`GET /api/skills/{id}`),
  регистрация пути в `api/src/openapi.yaml`; перегенерация `@repo/api`
  (`npm --workspace @repo/api run generate`) добавит клиент/hook/типы/Zod-схему в
  `packages/api/base/codegen/**` для новой операции (тег `Skills`, группа `skillsController`).
- **Mock-режим**: `packages/api/base/mock-scenarios.ts` — новый датасет вопросов по `id` навыка и
  маршрут `GET /api/skills/:id` с обработкой "не найдено".
- **Frontend**: `app/catalog/[id]/page.tsx` (полная реализация вместо заглушки), новые
  server-компоненты в `app/catalog/[id]/_components/`.
- **Тесты**: component/unit-тесты на новый мок-маршрут и на рендер страницы/компонентов навыка.
