## ADDED Requirements

### Requirement: Popover primitive

Пакет `@repo/core` SHALL экспортировать компонент `Popover` (триггер + немодальный позиционируемый
попап), открывающийся по активации триггера, позиционируемый относительно триггера, принимающий
`className` для задания размеров и оформления попапа, закрывающийся по Escape и по клику вне своей
области, и возвращающий фокус триггеру при закрытии с клавиатуры. Триггер SHALL сохранять непустой
accessible name и связь с попапом для assistive technologies.

#### Scenario: Открытие Popover по активации триггера

- **WHEN** пользователь активирует триггер Popover
- **THEN** попап становится видимым и содержит переданные `children`

#### Scenario: Escape закрывает Popover и возвращает фокус

- **WHEN** Popover открыт и пользователь нажимает Escape
- **THEN** попап закрывается и фокус возвращается на элемент, который открыл Popover

#### Scenario: Клик вне попапа закрывает его

- **WHEN** Popover открыт и пользователь кликает вне области попапа и триггера
- **THEN** попап закрывается

#### Scenario: Триггер имеет доступное имя

- **WHEN** триггер Popover отрендерен без видимого текста (только иконка или изображение)
- **THEN** триггер имеет непустой accessible name через `aria-label`
