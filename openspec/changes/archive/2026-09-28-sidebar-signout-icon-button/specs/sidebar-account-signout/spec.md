## Purpose

Определяет, как авторизованный пользователь видит и использует свой профиль и действие выхода из аккаунта в десктопном Sidebar, без промежуточного всплывающего меню.

## ADDED Requirements

### Requirement: Профиль в Sidebar без Popover

Для авторизованного пользователя Sidebar SHALL отображать блок профиля (`AccountSummary`) как статичный, некликабельный элемент, без открытия Popover при клике по нему.

#### Scenario: Клик по блоку профиля не открывает меню

- **WHEN** авторизованный пользователь кликает по блоку профиля (`AccountSummary`) в Sidebar
- **THEN** никакое всплывающее меню не открывается и видимое состояние страницы не меняется

### Requirement: Прямая кнопка выхода рядом с профилем

Для авторизованного пользователя Sidebar SHALL отображать кнопку выхода из аккаунта в виде одиночной иконки, расположенную рядом с блоком профиля, без фонового цвета и без границы в состоянии покоя.

#### Scenario: Кнопка выхода видна сразу

- **WHEN** авторизованный пользователь видит Sidebar
- **THEN** рядом с блоком профиля отображается кнопка выхода с иконкой выхода, без предварительного открытия какого-либо меню

#### Scenario: Клик по кнопке выхода завершает сессию

- **WHEN** авторизованный пользователь нажимает на кнопку выхода в Sidebar
- **THEN** выполняется тот же процесс выхода из аккаунта, что и ранее (инвалидация сессии, редирект/обновление состояния гостя), без дополнительного шага подтверждения через Popover

### Requirement: Индикация ожидания при выходе

Пока запрос выхода из аккаунта выполняется, Sidebar SHALL отображать индикатор загрузки на месте иконки выхода и SHALL блокировать повторное нажатие кнопки выхода до завершения запроса.

#### Scenario: Лоадер отображается во время запроса выхода

- **WHEN** авторизованный пользователь нажимает на кнопку выхода и запрос выхода ещё не завершён
- **THEN** иконка выхода заменяется индикатором загрузки, а кнопка выхода недоступна для повторного нажатия

#### Scenario: Лоадер исчезает после завершения запроса

- **WHEN** запрос выхода завершается
- **THEN** индикатор загрузки скрывается и (в случае ошибки без обновления страницы) кнопка выхода снова доступна для нажатия
