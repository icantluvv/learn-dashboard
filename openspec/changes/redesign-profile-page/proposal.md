## Why

Текущий экран авторизованного профиля (`app/(main)/profile/_components/profile-view/profile-authenticated.tsx`)
показывает только аватар-инициал, имя, email, роль и кнопку выхода на сером фоне — пользователь не
видит фамилию, возраст и свой прогресс по изученным навыкам, а фото профиля вообще нельзя изменить
после регистрации. Это не соответствует референсному макету (карточка с градиентным баннером,
крупным аватаром с возможностью замены, блоком skills) и не использует уже собираемые при
регистрации данные (`lastName`, `age`, `role`, `completedSkillsCount`).

## What Changes

- Редизайн визуального оформления экрана авторизованного профиля: карточка с градиентным
  header-баннером, крупным круглым аватаром поверх баннера, блоком идентичности (имя + фамилия,
  возраст, роль, email) и секцией изученных навыков.
- Аватар становится кликабельным: нажатие на круг с фото/инициалом открывает выбор файла и сразу
  загружает новое фото профиля без перехода на отдельную страницу.
- **Новая серверная возможность**: эндпоинт/server action обновления аватара уже
  зарегистрированного пользователя — переиспользует существующую валидацию файла
  (`src/modules/auth/avatar.ts`) и хранилище (`user_avatar`), которых сегодня достаточно только для
  аватара при регистрации.
- Секция «Изученные навыки» на профиле группирует навыки пользователя по направлениям (`core`:
  `frontend`/`backend`/`devops`/`design`), а не просто показывает счётчик
  `completedSkillsCount`. Для этого вводится серверный запрос, возвращающий изученные навыки
  текущего пользователя с привязкой к направлению.
- Экран профиля продолжает оставаться Server Component с гидратацией данных пользователя; экраны
  загрузки/ошибки/гостя не меняются.

## Capabilities

### New Capabilities

- `profile-avatar-update`: загрузка и замена фото профиля уже авторизованным пользователем прямо со
  страницы `/profile` (клик по аватару → выбор файла → валидация → сохранение → обновление
  отображаемого фото).
- `profile-completed-skills-summary`: серверное получение и группировка изученных текущим
  пользователем навыков по направлениям (`core`) для отображения на странице профиля.

### Modified Capabilities

- `profile-page`: экран авторизованного профиля дополняется полями фамилии, возраста, визуально
  переоформляется (баннер, карточка) и получает секцию изученных навыков по направлениям; также
  аватар на этом экране становится интерактивным триггером замены фото.

## Impact

- `app/(main)/profile/_components/profile-view/profile-authenticated.tsx` и соседние файлы —
  полная переработка верстки.
- Новый client-компонент выбора/загрузки файла аватара (в `app/(main)/profile/_components/` или
  `src/modules/auth`, по месту использования — решается в design.md).
- `src/modules/auth/avatar.ts`, `src/modules/auth/avatar-repository.server.ts` — переиспользуются
  для нового пути обновления аватара вне регистрации; потребуется новый server action/route handler.
- `src/modules/skills/server/skill-completion-repository.server.ts` — добавляется функция выборки
  изученных навыков пользователя с направлением (`core`), либо новый repository-модуль.
- `src/lib/auth/get-session.ts`, `CurrentUser` — используются существующие поля (`lastName`, `age`,
  `role`, `image`, `completedSkillsCount`), без изменения контракта better-auth.
- `openspec/specs/profile-page/spec.md` — дельта-спек на изменённые требования.
- Новые `openspec/specs/profile-avatar-update/spec.md` и
  `openspec/specs/profile-completed-skills-summary/spec.md`.
