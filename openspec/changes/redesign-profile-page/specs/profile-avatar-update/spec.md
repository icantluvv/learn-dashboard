## Purpose

Позволяет уже зарегистрированному и авторизованному пользователю заменить фото своего профиля прямо
со страницы `/profile`, без прохождения повторной регистрации.

## ADDED Requirements

### Requirement: Авторизованный пользователь может заменить фото профиля

Система SHALL предоставлять авторизованному пользователю возможность загрузить новый файл
изображения и заменить им текущее фото профиля (`image`). После успешной загрузки SHALL немедленно
отображаться новое фото без перезагрузки страницы.

#### Scenario: Успешная замена фото

- **WHEN** авторизованный пользователь выбирает корректный файл изображения (JPEG, PNG или WebP, не
  более 5 МБ, с содержимым, соответствующим заявленному формату)
- **THEN** новое фото сохраняется, становится текущим аватаром пользователя и немедленно отображается
  на экране профиля

### Requirement: Некорректный файл аватара отклоняется без изменения текущего фото

Система SHALL валидировать выбранный файл теми же правилами, что используются при регистрации
(допустимые MIME-типы `image/jpeg`, `image/png`, `image/webp`; ненулевой размер; не более 5 МБ;
сигнатура содержимого файла соответствует заявленному MIME-типу). При нарушении любого из этих
правил SHALL отображаться понятное сообщение об ошибке, а текущее фото пользователя SHALL остаться
неизменным.

#### Scenario: Файл недопустимого формата

- **WHEN** пользователь выбирает файл с MIME-типом, отличным от `image/jpeg`, `image/png` или
  `image/webp`
- **THEN** система отклоняет файл, показывает сообщение о недопустимом формате, и текущее фото
  профиля не меняется

#### Scenario: Файл превышает допустимый размер

- **WHEN** пользователь выбирает файл изображения размером более 5 МБ
- **THEN** система отклоняет файл, показывает сообщение о превышении допустимого размера, и текущее
  фото профиля не меняется

#### Scenario: Содержимое файла не соответствует заявленному формату

- **WHEN** пользователь выбирает файл, чьё содержимое (сигнатура байтов) не соответствует заявленному
  MIME-типу
- **THEN** система отклоняет файл, показывает сообщение о несоответствии содержимого формату, и
  текущее фото профиля не меняется

### Requirement: Доступ к замене аватара требует активной сессии

Система SHALL выполнять замену аватара только для запроса, сопровождаемого действительной сессией
авторизованного пользователя. Запрос на замену аватара без действительной сессии SHALL быть отклонён
и SHALL не создавать и не изменять никаких данных аватара.

#### Scenario: Запрос без действительной сессии

- **WHEN** запрос на замену аватара выполняется без действительной сессии пользователя
- **THEN** система отклоняет запрос и не сохраняет и не изменяет данные аватара
