## Purpose

Предоставляет серверную выборку изученных текущим пользователем навыков, сгруппированных по
направлениям (`core`), для отображения на странице профиля.

## ADDED Requirements

### Requirement: Система предоставляет изученные навыки пользователя, сгруппированные по направлениям

Система SHALL предоставлять для текущего авторизованного пользователя список его изученных навыков,
сгруппированный по направлению (`core`: `frontend`, `backend`, `devops`, `design`). Каждая группа
SHALL содержать идентификатор и название направления и перечень изученных в нём навыков
пользователя.

#### Scenario: У пользователя есть изученные навыки в нескольких направлениях

- **WHEN** текущий пользователь отметил изученными навыки, относящиеся к двум и более направлениям
- **THEN** выборка содержит по одной группе на каждое направление, в котором есть хотя бы один
  изученный навык, с перечнем этих навыков

#### Scenario: У пользователя нет изученных навыков

- **WHEN** текущий пользователь не отметил изученным ни один навык
- **THEN** выборка содержит пустой список групп

### Requirement: Группировка не включает направления без изученных навыков

Выборка изученных навыков SHALL содержать только те направления, в которых у текущего пользователя
есть хотя бы один изученный навык; направления без изученных навыков SHALL отсутствовать в
результате.

#### Scenario: У пользователя изучены навыки только в одном направлении

- **WHEN** текущий пользователь отметил изученными навыки только в направлении `frontend`, а в
  остальных направлениях изученных навыков нет
- **THEN** выборка содержит ровно одну группу — `frontend` — и не содержит групп для остальных
  направлений
