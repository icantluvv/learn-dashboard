## Why

Форма регистрации сейчас не различает, кем является новый пользователь (разработчик, аналитик,
студент, начинающий), и собирает имя одним полем без фамилии. Эти данные нужны, чтобы персонально
обращаться к пользователю и показывать его роль и полное имя (имя и фамилию) в личном кабинете —
сейчас такой информации в профиле просто нет.

## What Changes

- В форму регистрации (`/sign-up`) добавляется обязательное поле `role` — select с вариантами
  «Разработчик», «Аналитик», «Студент», «Начинающий».
- Поле `name` на форме регистрации дополняется отдельным необязательным полем `lastName`
  (фамилия); `name` остаётся именем, `lastName` — фамилией, оба хранятся раздельно.
- Поле `age` становится необязательным (ранее было обязательным); `avatar` остаётся
  необязательным без изменений.
- Контракт `GET /api/me` (`AuthMe`) дополняется обязательным полем `role` (enum: `developer`,
  `analyst`, `student`, `beginner`) и необязательным полем `lastName` (string); поле `age`
  переводится из обязательных в необязательные.
- Серверная регистрация (`better-auth` `additionalFields`) сохраняет `lastName` и `role` вместе с
  остальными полями профиля; `lastName` и `age` допускают отсутствие значения.
- Страница личного кабинета (`/profile`, экран авторизованного пользователя) отображает фамилию
  рядом с именем, если она указана, и человекочитаемое название роли.
- **BREAKING**: `GET /api/me` теперь возвращает дополнительное обязательное поле `role`;
  существующие пользователи без этого значения будут обработаны через значение по умолчанию,
  заданное в рамках миграции (см. `design.md`). Переход `age` и добавление `lastName` в
  необязательные поля не является breaking-изменением контракта.

## Capabilities

### New Capabilities

(нет — расширяются существующие capability)

### Modified Capabilities

- `user-auth`: регистрация и контракт `authMe` получают новое обязательное поле `role` и
  необязательное `lastName`; поле `age` становится необязательным.
- `auth-pages`: форма `/sign-up` получает необязательное поле «Фамилия» и обязательное «Кем вы
  являетесь» (select), поле «Возраст» становится необязательным.
- `profile-page`: экран авторизованного профиля отображает полное имя (имя + фамилия, если
  указана) и название роли пользователя.

## Impact

- `api/src/components/schemas/AuthMe.yaml` — новые поля `lastName`, `role`; регенерация
  `packages/api` (`npm --workspace @repo/api run gen`).
- `src/lib/auth/server.ts` — `user.additionalFields` (`lastName`, `role`).
- `src/lib/auth/get-session.ts` — интерфейс `CurrentUser` и маппинг сессии.
- `src/lib/auth/constants.ts` — новый enum значений роли.
- `src/modules/auth/schemas.ts`, `src/modules/auth/actions.ts` — Zod-схемы и `signUpAction`.
- `app/(auth)/sign-up/_components/sign-up-form/sign-up-form.tsx` и новый
  `app/(auth)/sign-up/_constants/role-options.ts` — поля формы.
- `app/(main)/profile/_components/profile-view/profile-authenticated.tsx` — вывод фамилии и роли.
- Существующие пользователи в БД без `role`: требуется решение о бэкофилле/дефолте (см.
  `design.md`); `lastName` и `age` остаются корректно `null` без миграции данных.
