## Context

`Sidebar` (`src/components/sidebar/sidebar.tsx`) уже использует Tailwind-токен `bg-sidebar`,
привязанный к CSS-переменной темы, и корректно темнеет в тёмной теме. `AccountDrawer` и `BottomNav`
— мобильные аналоги того же навигационного каркаса (desktop sidebar ↔ mobile drawer + bottom nav),
но используют другие источники цвета: хардкод `bg-white` и токен `bg-card` соответственно. См.
proposal.md — Why.

## Goals / Non-Goals

**Goals:**

- Фон `AccountDrawer` и `BottomNav` в тёмной теме визуально совпадает с фоном `Sidebar`.

**Non-Goals:**

- Не меняется состав, разметка или поведение навигации — только источник фонового цвета.
- Не вводятся новые CSS-токены — переиспользуется существующий `bg-sidebar`.

## Decisions

- Использовать уже существующий токен `bg-sidebar` вместо `bg-card`/`bg-white` в обоих
  компонентах. Альтернатива — завести отдельный токен `bg-mobile-nav` — отклонена: нет причины
  иметь два разных токена для одного и того же визуального фона (sidebar/drawer/bottom-nav —
  один и тот же навигационный каркас).

## Risks / Trade-offs

- [Риск: `bg-sidebar` в светлой теме может отличаться оттенком от прежнего `bg-card`/`white`] →
  Митигация: токен `bg-sidebar` уже используется в десктопном сайдбаре на тех же маршрутах, визуальная
  консистентность между desktop и mobile — желаемый результат, а не побочный эффект.
