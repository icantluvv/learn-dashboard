## Why

Изученные навыки передавались в профиль с сервера и могли оставаться устаревшими после изменения
отметки в каталоге. Профиль должен получать актуальный список через API и обновлять его при
возвращении без полной перезагрузки страницы.

## What Changes

- Добавляется `GET /api/me/completed-skills`, контракт и generated client/hooks/mocks/schemas.
- Профиль получает пользователя и изученные навыки через TanStack Query без server prefetch.
- Изменение отметки инвалидирует кэш изученных навыков; ключ списка разделён по пользователям.
- Добавляются loading/error/retry/empty состояния списка и ссылки на изученные навыки.
- **BREAKING**: ошибка auth-query, включая 401, отображает ошибку профиля вместо гостевого экрана.
- Карточка пользователя, аватар и группы навыков выделяются в локальные компоненты.

## Capabilities

### New Capabilities

- `profile-completed-skills-api`: получение и синхронизация списка через API, состояния и навигация.

### Modified Capabilities

- `profile-page`: клиентская загрузка без гидратации и единое отображение ошибок auth-query.

## Impact

- `/profile`, `/catalog/[core]/[id]`, `/api/me/completed-skills`.
- `api/src/openapi.yaml`, `packages/api/base/client.ts` и generated output Kubb.
- Компоненты профиля, component tests и `docs/profile-completed-skills-cache.md`.
- Изменения темы и слайдера не входят в change. Новые зависимости не требуются.
- Возможность группировки уже описана в активном `redesign-profile-page`; новый capability
  описывает только API и клиентское поведение, не дублирует базовую группировку.

## Quality impact

- Риск: P1; особенно важны изоляция пользователей и актуальность списка после SPA-навигации.
- Проверки: Unit для endpoint/маршрутизации, Component для состояний, E2E для сессии и обновления.
- Ручная проверка: retry после сбоя с сохранением ранее полученных данных.
- Откат: вернуть серверную выборку/гидратацию и прежний выбор экранов, удалить новый endpoint.
- Change создан после реализации. Порядок TDD и успешные проверки не подтверждены; задачи
  остаются открытыми до выполнения verification gates.
