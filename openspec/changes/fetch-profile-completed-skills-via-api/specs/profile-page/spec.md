## MODIFIED Requirements

### Requirement: Страница профиля рендерится на сервере с prefetch данных пользователя

Страница `/profile` SHALL сохранять серверную оболочку, но SHALL загружать данные пользователя
на клиенте без серверного prefetch и гидратации кэша профиля.

#### Scenario: Открытие страницы профиля

- **GIVEN** клиентский кэш пользователя пуст
- **WHEN** пользователь открывает `/profile`
- **THEN** клиент запрашивает данные пользователя и показывает загрузку до завершения запроса

### Requirement: Клиентская часть страницы профиля выбирает экран по состоянию запроса

Клиентская часть `/profile` SHALL отображать ровно один экран: загрузку, ошибку или авторизованный
профиль. Ошибка любого auth-запроса, включая 401/403/500 и сетевой сбой, SHALL отображаться как
ошибка профиля; компонент выбора экранов SHALL NOT инициировать редирект. Отсутствие данных после
завершения запроса SHALL также отображаться как ошибка.

#### Scenario: Запрос выполняется

- **WHEN** запрос пользователя находится в состоянии загрузки
- **THEN** отображается только экран загрузки

#### Scenario: Запрос завершился ошибкой, не связанной с отсутствием сессии

- **WHEN** запрос пользователя завершается ошибкой 403, 500 или сетевым сбоем
- **THEN** отображается только экран ошибки, а компонент выбора экранов не инициирует редирект

#### Scenario: Пользователь не авторизован

- **WHEN** запрос пользователя завершается ошибкой 401
- **THEN** отображается только экран ошибки, а компонент выбора экранов не инициирует редирект

#### Scenario: Ответ не содержит пользователя

- **WHEN** запрос завершён без ошибки, но данные пользователя отсутствуют
- **THEN** отображается только экран ошибки

#### Scenario: Пользователь авторизован

- **WHEN** запрос успешно возвращает данные пользователя
- **THEN** отображается только авторизованный профиль с этими данными

## REMOVED Requirements

### Requirement: Гостевой экран профиля предлагает войти или зарегистрироваться

**Reason**: Ошибка отсутствия сессии теперь отображается общим экраном ошибки профиля.
**Migration**: Вход и регистрация остаются доступны через существующие маршруты авторизации.
