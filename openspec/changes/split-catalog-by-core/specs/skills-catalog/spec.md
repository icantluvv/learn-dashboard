## MODIFIED Requirements

### Requirement: Отображение списка навыков

Система SHALL отображать по одной карточке на каждый навык, возвращённый `GET /api/skills` для
текущего направления. Карточка SHALL показывать тему, сложность (на русском языке), название и
количество вопросов, и SHALL вести по клику на `/catalog/{core}/{id}` соответствующего навыка, где
`{core}` — направление раздела, в котором находится пользователь.

#### Scenario: Успешная загрузка списка

- **WHEN** пользователь находится на `/catalog/{core}`, запрос `GET /api/skills` завершается
  успешно и возвращает непустой список
- **THEN** для каждого элемента списка отображается карточка с темой, названием, сложностью и
  количеством вопросов
- **THEN** карточка ведёт по ссылке `/catalog/{core}/{id}` этого навыка

#### Scenario: Список ограничен направлением раздела

- **WHEN** пользователь открывает `/catalog/frontend`
- **THEN** запрос списка навыков отправляется с фильтром `core=frontend`
- **THEN** отображаются только карточки навыков направления `frontend`
