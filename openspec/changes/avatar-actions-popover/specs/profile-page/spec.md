## ADDED Requirements

### Requirement: Клик по аватарке профиля открывает поповер действий

Круг аватарки на экране авторизованного профиля SHALL реагировать на клик/тап открытием поповера
действий вместо немедленного открытия системного диалога выбора файла. Поповер SHALL содержать
пункт «Загрузить новое фото». Поповер SHALL содержать пункт «Удалить фото» тогда и только тогда,
когда у текущего пользователя задан `image`; если `image` отсутствует, пункт удаления в поповере
SHALL NOT отображаться.

#### Scenario: Клик по аватарке без фото

- **WHEN** пользователь без загруженного `image` кликает по кругу аватарки
- **THEN** открывается поповер с единственным пунктом «Загрузить новое фото» и без пункта удаления

#### Scenario: Клик по аватарке с фото

- **WHEN** пользователь с загруженным `image` кликает по кругу аватарки
- **THEN** открывается поповер с двумя пунктами: «Загрузить новое фото» и «Удалить фото»

### Requirement: Пункт «Загрузить новое фото» открывает выбор файла

Выбор пункта «Загрузить новое фото» в поповере SHALL открывать системный диалог выбора файла с тем
же набором допустимых типов и ограничением размера, что действовали для прежнего прямого клика по
аватарке, и SHALL использовать существующий процесс загрузки (валидация, превью, вызов action
обновления аватара, оптимистичное обновление кэша данных пользователя).

#### Scenario: Загрузка нового фото через поповер

- **WHEN** пользователь выбирает «Загрузить новое фото» в поповере и затем выбирает корректный файл
  изображения в системном диалоге
- **THEN** поповер закрывается, запускается существующий процесс загрузки аватара и после успешного
  завершения кэш данных пользователя отражает новый `image`

### Requirement: Пункт «Удалить фото» сбрасывает аватар пользователя

Выбор пункта «Удалить фото» в поповере SHALL вызывать удаление текущего сохранённого аватара
пользователя и сброс `image` пользователя до отсутствующего значения. После успешного удаления
круг аватарки SHALL отображать дефолтное представление (первая буква имени на брендовом фоне), а
кэш данных текущего пользователя SHALL быть обновлён без обязательного повторного запроса. Если
удаление завершается ошибкой, текущее изображение SHALL остаться без изменений и пользователю
SHALL быть показано сообщение об ошибке.

#### Scenario: Успешное удаление фото

- **WHEN** пользователь с загруженным `image` выбирает «Удалить фото» в поповере
- **THEN** сохранённый файл аватара удаляется, `image` пользователя сбрасывается, круг аватарки
  показывает первую букву имени на брендовом фоне, и кэш данных пользователя обновлён без
  обязательного повторного запроса

#### Scenario: Ошибка при удалении фото

- **WHEN** запрос удаления аватара завершается ошибкой
- **THEN** текущее изображение пользователя остаётся отображённым без изменений и показывается
  сообщение об ошибке
