# home-dashboard Specification

## Purpose

Определяет, что видит пользователь на главной странице дашборда: персонализированное приветствие
и сводную статистику каталога навыков, без разбивки по уровням сложности.

## Requirements

### Requirement: Персонализированное приветствие

Главная страница SHALL отображать заголовок-приветствие, зависящий от статуса аутентификации
текущего пользователя, вместо статичного названия сервиса.

#### Scenario: Авторизованный пользователь видит приветствие с именем

- **WHEN** страница дашборда рендерится для аутентифицированного пользователя с именем «Анна»
- **THEN** заголовок отображает «С возвращением, Анна»

#### Scenario: Неавторизованный посетитель видит нейтральное приветствие

- **WHEN** страница дашборда рендерится для пользователя без активной сессии
- **THEN** заголовок отображает «Добро пожаловать» без имени и без плейсхолдера имени

#### Scenario: Подзаголовок отражает призыв к действию

- **WHEN** страница дашборда рендерится независимо от статуса аутентификации
- **THEN** под заголовком отображается текст «К чему приступим сегодня?»

### Requirement: Сводная статистика каталога без разбивки по сложности

Главная страница SHALL отображать карточки сводной статистики каталога (количество навыков, тем и
вопросов) и SHALL NOT отображать отдельные карточки количества навыков по уровням сложности
(лёгкий/средний/сложный).

#### Scenario: Отображаются только карточки сводной статистики

- **WHEN** данные каталога успешно загружены и содержат навыки всех уровней сложности
- **THEN** дашборд показывает карточки «Навыков», «Тем» и «Вопросов»
- **AND** дашборд не показывает карточки «Лёгкий», «Средний» или «Сложный»

#### Scenario: Карточка статистики содержит иконку и декоративную мини-диаграмму

- **WHEN** карточка сводной статистики отображается с числовым значением
- **THEN** карточка содержит иконку-бейдж, соответствующую своей метрике
- **AND** карточка содержит декоративный визуальный элемент (мини-диаграмму), не несущий
  дополнительной интерактивности и скрытый от вспомогательных технологий

### Requirement: Сводные показатели каталога

Главная страница `/` SHALL отображать сводные показатели, вычисленные из списка навыков: общее
количество навыков, количество различных тем, общее количество вопросов по всем навыкам и
распределение навыков по уровням сложности. Подписи уровней сложности SHALL быть на русском языке —
теми же, что использует карточка навыка.

#### Scenario: Показатели по непустому каталогу

- **WHEN** список навыков успешно загружен и содержит 5 навыков по 2 темам с суммарно 40 вопросами
- **THEN** дашборд показывает 5 как общее количество навыков, 2 как количество тем и 40 как общее
  количество вопросов

#### Scenario: Распределение по сложности

- **WHEN** список навыков успешно загружен и содержит навыки нескольких уровней сложности
- **THEN** дашборд показывает количество навыков для каждого уровня сложности с подписью на русском
  языке

#### Scenario: Уровень сложности без навыков

- **WHEN** в списке навыков нет ни одного навыка некоторого уровня сложности
- **THEN** этот уровень либо не отображается, либо отображается со значением 0 — но не с пустым
  значением и не с ошибкой

### Requirement: Состояния загрузки дашборда

Пока список навыков загружается, главная страница SHALL показывать плейсхолдеры вместо значений
показателей и SHALL NOT показывать сообщение об ошибке. Если загрузка завершается ошибкой, страница
SHALL показать сообщение об ошибке вместо значений показателей. Если список успешно загружен и пуст,
страница SHALL сообщить об отсутствии навыков вместо нулевых показателей.

#### Scenario: Загрузка показателей

- **WHEN** запрос списка навыков находится в состоянии загрузки
- **THEN** вместо значений показателей отображаются плейсхолдеры, а сообщение об ошибке не
  отображается

#### Scenario: Ошибка загрузки показателей

- **WHEN** запрос списка навыков завершается ошибкой
- **THEN** отображается сообщение об ошибке, а значения показателей не отображаются

#### Scenario: Пустой каталог

- **WHEN** запрос списка навыков завершается успешно и возвращает пустой список
- **THEN** отображается сообщение об отсутствии навыков вместо набора нулевых показателей

### Requirement: Общая информация о сервисе

Главная страница SHALL содержать краткий вводный блок о назначении сервиса и ссылку на каталог
`/catalog`.

#### Scenario: Переход в каталог с главной

- **WHEN** пользователь открывает `/` и активирует ссылку на каталог
- **THEN** происходит переход на `/catalog`, где отображаются панель фильтров и сетка карточек

#### Scenario: Вводный блок присутствует

- **WHEN** пользователь открывает `/`
- **THEN** на странице отображается заголовок и краткое описание назначения сервиса
