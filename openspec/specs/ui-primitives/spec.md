# ui-primitives Specification

## Purpose

Предоставляет набор переиспользуемых, доступных UI-примитивов (Button, Select, Card, Skeleton,
Slider, Input/SearchField, Drawer) на базе Base UI, которые заменяют `@heroui/react` и служат
единственным источником интерактивных UI-примитивов для приложения.

## Requirements

### Requirement: Button primitive

Пакет `@repo/core` SHALL экспортировать компонент `Button`, поддерживающий варианты `solid`,
`outline` и `ghost`, состояние `disabled`, режим `iconOnly` (без текстового содержимого, с
обязательным `aria-label`), растяжение на всю ширину контейнера и обработчик клика/нажатия.

#### Scenario: Обычная кнопка вызывает обработчик по клику

- **WHEN** пользователь кликает по кнопке в состоянии `enabled`
- **THEN** переданный обработчик нажатия вызывается один раз

#### Scenario: Disabled-кнопка не вызывает обработчик

- **WHEN** пользователь кликает по кнопке с `disabled`
- **THEN** обработчик нажатия не вызывается и кнопка помечена как недоступная для assistive
  technologies (`aria-disabled` или нативный `disabled`)

#### Scenario: Icon-only кнопка требует доступного имени

- **WHEN** кнопка отрендерена в режиме `iconOnly` без видимого текста
- **THEN** кнопка имеет непустой accessible name через `aria-label`

### Requirement: Select primitive

Пакет `@repo/core` SHALL экспортировать компонент `Select` (триггер + попап со списком опций),
поддерживающий управляемое значение (`value`/`onValueChange`), `placeholder` при отсутствии
значения, произвольный список опций с уникальными `id`, и клавиатурную навигацию (открытие по
Enter/Space, перемещение по опциям стрелками, выбор по Enter, закрытие по Escape).

#### Scenario: Выбор опции обновляет значение

- **WHEN** пользователь открывает Select и выбирает опцию с идентификатором `X`
- **THEN** компонент вызывает `onValueChange` с `X` и триггер отображает подпись выбранной опции

#### Scenario: Пустое значение показывает placeholder

- **WHEN** `value` равен `null`/`undefined`
- **THEN** триггер отображает переданный `placeholder`

#### Scenario: Список опций доступен с клавиатуры

- **WHEN** триггер в фокусе и пользователь нажимает Enter, затем стрелку вниз и Enter
- **THEN** попап открывается, фокус перемещается на следующую опцию, и она становится выбранным
  значением

### Requirement: Card primitive

Пакет `@repo/core` SHALL экспортировать контейнерный компонент `Card`, принимающий `className` для
композиции с Tailwind-утилитами и рендерящий переданные `children` без навязывания собственных
интерактивных ролей.

#### Scenario: Card рендерит переданное содержимое

- **WHEN** `Card` получает `children` и `className`
- **THEN** содержимое рендерится внутри контейнера, а переданный `className` применяется к
  корневому элементу без потери базовых стилей примитива

### Requirement: Skeleton primitive

Пакет `@repo/core` SHALL экспортировать компонент `Skeleton` для плейсхолдера загрузки, принимающий
`className` для управления размерами и помечающий себя как декоративный для assistive technologies.

#### Scenario: Skeleton скрыт от screen reader

- **WHEN** `Skeleton` отрендерен на странице
- **THEN** элемент имеет `aria-hidden="true"` (или эквивалентную декоративную семантику) и не
  объявляется screen reader как интерактивный или содержащий значимый текст

### Requirement: Range slider primitive

Пакет `@repo/core` SHALL экспортировать компонент `Slider`, поддерживающий одиночное и диапазонное
(два thumb) управляемое значение, `minValue`/`maxValue`, обработчик финального изменения
(`onValueCommitted` или эквивалент) и клавиатурное управление каждым thumb стрелками.

#### Scenario: Перемещение диапазона вызывает commit-обработчик один раз

- **WHEN** пользователь перетаскивает один из двух thumb от начального значения к новому и
  отпускает указатель
- **THEN** compit-обработчик вызывается один раз с итоговой парой `[min, max]`, а не на каждое
  промежуточное перемещение

#### Scenario: Thumb управляется с клавиатуры

- **WHEN** thumb в фокусе и пользователь нажимает стрелку вправо
- **THEN** значение этого thumb увеличивается на шаг и остаётся в границах
  `[minValue, maxValue]`, не пересекая соседний thumb

### Requirement: Search input primitive

Пакет `@repo/core` SHALL экспортировать текстовый `Input`-примитив, пригодный для реализации поиска:
управляемое строковое значение, иконка поиска, кнопка очистки, видимая только при непустом значении,
и `placeholder`.

#### Scenario: Кнопка очистки сбрасывает значение

- **WHEN** значение поля непустое и пользователь нажимает кнопку очистки
- **THEN** значение становится пустой строкой и обработчик изменения вызывается с пустой строкой

#### Scenario: Кнопка очистки скрыта при пустом значении

- **WHEN** значение поля — пустая строка
- **THEN** кнопка очистки не отображается (или не доступна для взаимодействия)

### Requirement: Drawer primitive

Пакет `@repo/core` SHALL экспортировать компонент `Drawer` (триггер + модальная панель),
открывающийся по активации триггера, блокирующий фокус внутри себя пока открыт (focus trap),
закрывающийся по Escape и клику по backdrop, и возвращающий фокус триггеру при закрытии.

#### Scenario: Открытие Drawer перемещает фокус внутрь

- **WHEN** пользователь активирует триггер Drawer
- **THEN** панель становится видимой, а фокус перемещается на первый фокусируемый элемент внутри
  неё

#### Scenario: Escape закрывает Drawer и возвращает фокус

- **WHEN** Drawer открыт и пользователь нажимает Escape
- **THEN** панель закрывается и фокус возвращается на элемент, который открыл Drawer

### Requirement: No dependency on `@heroui/react`

После завершения миграции приложение SHALL не импортировать `@heroui/react` ни в одном файле, и
пакет SHALL отсутствовать в зависимостях `package.json`.

#### Scenario: Поиск импортов heroui не даёт результатов

- **WHEN** в репозитории выполняется поиск строки `@heroui/react` по `app/` и `src/`
- **THEN** совпадений не найдено
