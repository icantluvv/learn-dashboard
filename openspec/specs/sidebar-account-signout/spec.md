# sidebar-account-signout Specification

## Purpose

Определяет, как авторизованный пользователь видит и использует свой профиль и действие выхода из
аккаунта в десктопном Sidebar, без промежуточного всплывающего меню.

## Requirements

### Requirement: Профиль в Sidebar без Popover

Для авторизованного пользователя Sidebar SHALL отображать блок профиля (`AccountSummary`) как
статичный, некликабельный элемент, без открытия Popover при клике по нему.

#### Scenario: Клик по блоку профиля не открывает меню

- **WHEN** авторизованный пользователь кликает по блоку профиля (`AccountSummary`) в Sidebar
- **THEN** никакое всплывающее меню не открывается и видимое состояние страницы не меняется
