# skills-catalog Specification

## Purpose

Показывает пользователю список доступных навыков текущего направления в виде карточек на странице
`/catalog/{core}` и явно сообщает о состоянии загрузки, ошибке запроса или отсутствии результатов.

## Requirements

### Requirement: Отображение списка навыков

Система SHALL отображать по одной карточке на каждый навык, возвращённый `GET /api/skills` для
текущего направления. Карточка SHALL показывать тему, сложность (на русском языке), название и
количество вопросов, и SHALL вести по клику на `/catalog/{core}/{id}` соответствующего навыка, где
`{core}` — направление раздела, в котором находится пользователь.

#### Scenario: Успешная загрузка списка

- **WHEN** пользователь находится на `/catalog/{core}`, запрос `GET /api/skills` завершается
  успешно и возвращает непустой список
- **THEN** для каждого элемента списка отображается карточка с темой, названием, сложностью и
  количеством вопросов
- **THEN** карточка ведёт по ссылке `/catalog/{core}/{id}` этого навыка

#### Scenario: Список ограничен направлением раздела

- **WHEN** пользователь открывает `/catalog/frontend`
- **THEN** запрос списка навыков отправляется с фильтром `core=frontend`
- **THEN** отображаются только карточки навыков направления `frontend`

### Requirement: Индикация загрузки

Пока запрос списка навыков выполняется, система SHALL показывать сетку из плейсхолдеров-скелетонов
вместо карточек и SHALL не показывать текст ошибки или текст об отсутствии результатов в этот момент.

#### Scenario: Запрос ещё выполняется

- **WHEN** запрос `GET /api/skills` находится в состоянии загрузки
- **THEN** отображается сетка скелетон-карточек
- **THEN** текст ошибки и текст об отсутствии результатов не отображаются

### Requirement: Состояние ошибки

Если запрос списка навыков завершается ошибкой, система SHALL показать сообщение об ошибке вместо
сетки карточек.

#### Scenario: Запрос завершился ошибкой

- **WHEN** запрос `GET /api/skills` завершается ошибкой
- **THEN** отображается сообщение "Не удалось загрузить список навыков. Попробуйте обновить страницу."
- **THEN** карточки навыков не отображаются

### Requirement: Пустой результат

Если запрос успешно завершился, но список навыков пуст, система SHALL показать сообщение об
отсутствии результатов вместо пустой сетки.

#### Scenario: Список навыков пуст

- **WHEN** запрос `GET /api/skills` завершается успешно и возвращает пустой список
- **THEN** отображается сообщение "Скиллов по запросу не нашлось."
- **THEN** сетка карточек не отображается

### Requirement: Возврат к предыдущей странице

Система SHALL показывать кнопку "Назад" над списком навыков направления на `/catalog/{core}`,
когда направление доступно (`isAvailable`). Переход по кнопке SHALL возвращать пользователя на
предыдущую страницу истории браузера.

#### Scenario: Нажатие кнопки "Назад" на странице каталога направления

- **WHEN** пользователь находится на `/catalog/{core}` после перехода со страницы со списком
  направлений и нажимает кнопку "Назад"
- **THEN** пользователь возвращается на предыдущую страницу истории браузера (список направлений)

#### Scenario: Направление недоступно

- **WHEN** направление с данным `core` существует, но помечено как недоступное (`isAvailable`
  равно `false`)
- **THEN** кнопка "Назад" не отображается

### Requirement: Каталог доступен по адресу `/catalog`

Страница каталога навыков SHALL быть доступна по маршруту `/catalog`. Она SHALL содержать сетку
карточек навыков и панель фильтров, и SHALL сохранять всё ранее описанное поведение списка
(загрузка, ошибка, пустой результат) без изменений. Главная страница `/` SHALL NOT содержать сетку
карточек навыков и панель фильтров.

#### Scenario: Открытие каталога по прямому адресу

- **WHEN** пользователь открывает `/catalog`
- **THEN** отображаются панель фильтров и сетка карточек навыков в том же составе и раскладке, что и
  до переноса

#### Scenario: Главная больше не содержит каталог

- **WHEN** пользователь открывает `/`
- **THEN** сетка карточек навыков и панель фильтров на странице не отображаются

#### Scenario: Состояния списка сохраняются на новом адресе

- **WHEN** пользователь открывает `/catalog` и запрос списка навыков находится в состоянии загрузки,
  затем завершается ошибкой, затем возвращает пустой список
- **THEN** последовательно отображаются сетка скелетон-карточек, сообщение об ошибке и сообщение об
  отсутствии результатов — теми же текстами, что и до переноса
