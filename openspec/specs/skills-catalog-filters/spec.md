# skills-catalog-filters Specification

## Purpose

Позволяет пользователю сузить список навыков каталога по названию, теме, сложности и количеству
вопросов, хранит выбранные фильтры в URL и даёт способ сбросить их одним действием.

## Requirements

### Requirement: Поиск по названию

Система SHALL позволять пользователю ввести текст поиска и SHALL включать в результат только навыки,
чьё название содержит введённый текст без учёта регистра.

#### Scenario: Ввод текста поиска

- **WHEN** пользователь вводит текст в поле поиска
- **THEN** список карточек обновляется и содержит только навыки, название которых включает введённый
  текст (без учёта регистра)

### Requirement: Фильтр по теме

Система SHALL позволять выбрать одну тему из списка и SHALL включать в результат только навыки с
точно совпадающей темой.

#### Scenario: Выбор темы

- **WHEN** пользователь выбирает тему в фильтре
- **THEN** список карточек содержит только навыки с выбранной темой

### Requirement: Фильтр по сложности

Система SHALL позволять выбрать один уровень сложности (лёгкий/средний/сложный) и SHALL включать в
результат только навыки с точно совпадающей сложностью.

#### Scenario: Выбор сложности

- **WHEN** пользователь выбирает уровень сложности в фильтре
- **THEN** список карточек содержит только навыки с выбранной сложностью

### Requirement: Фильтр по количеству вопросов

Система SHALL позволять задать диапазон количества вопросов (минимум и максимум) и SHALL включать в
результат только навыки, чьё количество вопросов попадает в этот диапазон включительно.

#### Scenario: Выбор диапазона количества вопросов

- **WHEN** пользователь задаёт минимальное и максимальное значение количества вопросов
- **THEN** список карточек содержит только навыки, у которых `minQuestionsCount <= questionsCount <=
maxQuestionsCount`

### Requirement: Комбинирование фильтров

Система SHALL применять все одновременно заданные фильтры вместе (логическое И), а не по отдельности.

#### Scenario: Несколько активных фильтров

- **WHEN** одновременно заданы текст поиска, тема, сложность и/или диапазон количества вопросов
- **THEN** список карточек содержит только навыки, удовлетворяющие всем заданным фильтрам одновременно

### Requirement: Фильтры хранятся в URL

Система SHALL хранить текущее состояние всех фильтров в query-параметрах URL страницы, чтобы состояние
переживало обновление страницы и им можно было поделиться ссылкой.

#### Scenario: Обновление страницы с активными фильтрами

- **WHEN** пользователь задал один или несколько фильтров и обновляет страницу (или открывает
  сохранённую ссылку с теми же query-параметрами)
- **THEN** заданные фильтры остаются применёнными, и список карточек соответствует им

### Requirement: Сброс всех фильтров

Система SHALL предоставлять действие, которое одновременно очищает все активные фильтры и возвращает
список карточек к полному, неотфильтрованному состоянию.

#### Scenario: Нажатие кнопки сброса

- **WHEN** пользователь нажимает кнопку сброса фильтров
- **THEN** значения поиска, темы, сложности и диапазона количества вопросов очищаются
- **THEN** список карточек возвращается к полному списку навыков без фильтрации
